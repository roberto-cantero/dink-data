# Cloud GPUs from the start, in one Docker image

All GPU work runs on rented cloud GPUs in the same Linux Docker image production will use. The Windows PCs would have been free, but they meant a second environment, one fast GPU shared by two people, and a migration before launch. We choose the cheapest GPU that gives the same result, such as community RTX 4090s, and accept slower training. We never save money on anything that changes quality. Development has a $50 monthly budget, enforced by prepaid RunPod credit with auto-pay off and a 4-hour timer on every pod. M0 uses RunPod only. Modal waits for batch eval and Vast.ai for the M4 benchmark. A training run that measurably improves accuracy can go over it if both owners agree first.
