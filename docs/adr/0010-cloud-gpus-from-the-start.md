# Cloud GPUs from the start, in one Docker image

All GPU work runs on rented cloud GPUs in the same Linux Docker image production will use. The Windows PCs would have been free, but they meant a second environment, one fast GPU shared by two people, and a migration before launch. We choose the cheapest GPU that gives the same result, such as community RTX 4090s, and accept slower training. We never save money on anything that changes quality. Development has a $50 monthly budget with prepaid credit, spending limits and idle shutdown. A training run that measurably improves accuracy can go over it if both owners agree first.
