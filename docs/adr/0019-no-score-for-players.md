# Don't show the score to players

On 21 October 2026 PickleCam's CEO decided that DinkData won't report the score. Most players in PickleCam games are beginners, play for fun, or lose track of side-out scoring, so many games are scored wrongly on court. Players know their own score, so any score we report that differs from theirs looks wrong at once. A count that is off by one, such as 34 winners instead of 33, goes unnoticed. Players get only the report and their reels. Neither contains the final score, games won, points scored, rallies won, rule deviations, score calls, server numbers, a game target or a game winner. The game log and `stats.json` stay internal, because the score could be rebuilt from the game log's rally winners. The serve sequence may track the score in memory as weak evidence for rally winners and game ends, but no stage depends on it, and no pipeline file stores it. Rally-level gold labels keep the score as played, so we can measure how often players get it wrong. Bringing the score back needs a new ADR.
