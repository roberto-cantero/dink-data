# Cloudflare R2 for storage, and production keeps results only

We store sample videos, labels, calibrations, models and results in one R2 bucket, because downloads are free and it is independent of PickleCam's production systems. R2 has no object versioning, so labels and calibrations are written once to versioned paths. During M0 to M3, R2 is the shared development store, and the prototype's `dink run` reads its models from a local folder rather than from R2 (ADR 0018). After the prototype, in production, workers read each video from Bunny and keep only the results. Copying 67 TB of video a month into R2 would add about $1,000 to the bill every month.
